## Host ports

Apps publish no public host ports. LAN-bound exceptions: the three backup relays
above (`10.10.0.31:15432/15433/15984`) and a private RelayHub host port `18080`
(unverified).

## Storage paths

`/opt/apps/<service>/` holds app config and bind mounts (GitLab:
`/opt/apps/gitlab/{config,logs,data}`; CouchLoom releases and mode-0600 run
config under `/opt/apps/couchloom/`). Backup runner code, secrets and
pre-upgrade archives: `/opt/apps/homelab-backup/` and
`/etc/homelab-backup/secrets/` (rclone config, Mezon webhook, CouchDB proxy
token).

## Operations

- Swarm change: from Pi5, `docker service update` or `docker stack deploy`;
  stateful services (GitLab) must be scaled to 0 before a replacement task
  starts on the same bind mounts.
- Compose change: on VM100, back up the project source and data, validate with
  `docker compose config --quiet`, recreate only the target service.
- If a public route returns 502, check the `tasks.<service>` DNS answer from
  `edge-traefik-pi5` first; Traefik uses DNSRR because VIP connections across
  the overlay were unreliable.
- Retired, do not recreate without owner reconciliation: BDS app and its
  Cloudflare connector, GoClaw public route, OmniScan, Educates.

## Rollback

- RelayHub v1 → legacy: the `prod` Compose project is the rollback target;
  the legacy database `relayhub` on Pi5 is retained.
- Ollama, NetBird, CloudBeaver, SearXNG: pre-upgrade archives and specs under
  `/opt/apps/homelab-backup/runs/version-upgrade-20261031/<service>/`; roll
  back to the recorded previous digest
  ([upgrade ledger](./deployments/version-upgrade-2026-10-31.md)).
- CouchLoom: retained previous release directories and images (see service doc).
