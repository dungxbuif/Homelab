# Homepage Swarm Cutover - 2026-09-15

## Decision And Scope

Move only Homepage from VM100 Compose port `18081` to a portless Swarm service.
Pi5 remains manager, VM100 remains the compute node, and Orange Pi Traefik
remains file-provider-only. Public domains and Homepage content did not change.
No database, Redis, MyPocket, BDS, or Traefik label/provider change was made.

## Runtime

- Service: `homepage`, one replica constrained to `node.hostname==vm100-prod`.
- Image: `homelab/homepage:vm100-20260910` (VM100-local image ID
  `sha256:de6e051a47a49b19b12ff18a41b61c1a29e6fa08146a584e7aae5cb0b24c606b`).
- Network: `homelab-net`; no published host port.
- Health: `wget -qO- --timeout=3 http://localhost:80/`, 30s interval,
  5s timeout, three retries. The image has no built-in healthcheck; the former
  Compose file supplied it, so the Swarm service needed explicit health flags.
- Route: `homepage@file` -> `http://tasks.homepage:80` for `dungxbuif.com`
  and `www.dungxbuif.com`.
- Previous Compose container: `vm100-homepage`, stopped at 13:23:35 UTC.
  Its YAML and image are retained for rollback; `18081` has no listener.

## Overlay Incident And Gate

At approximately 13:10 UTC, the existing Orange Pi Traefik task started
returning 502 for multiple overlay upstreams (including n8n, pgAdmin, CouchDB,
RustFS, and NetBird), before the Homepage file route changed around 13:12 UTC.
A fresh curl container on the same Orange Pi could reach overlay services.
`docker service update --force edge_traefik` replaced the edge task and restored
public routes. No new 502 was found in that task's recent logs during the
stability window. This is a recovery observation, not a confirmed root cause
or durable fix. A later user-directed full migration proceeded with paired
edge-namespace and independent-overlay probes; the MezonHook canary supplied
the additional ARP evidence recorded in its own deployment note. Further
cutovers must keep that diagnostic/recovery gate and Compose rollback.

## Rollback

If the Homepage route fails, on VM100 start the retained container:

```sh
docker compose -f /opt/apps/homepage/run/docker-compose.yml start homepage
```

Then copy the saved Orange Pi dynamic YAML backup **into**
`/opt/edge/traefik/dynamic.yml` (do not replace the bind-mounted inode), and
verify the restored route, source/live hash, and both public domains. If other
overlay routes also fail, diagnose/recover the edge task separately; restoring
only the Homepage URL cannot repair a cluster-wide overlay failure.
