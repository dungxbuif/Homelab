# VM100 OpenClaw And n8n Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy OpenClaw and n8n on VM100 while keeping Orange Pi Traefik as the only edge router and leaving MyPocket, GoClaw, and existing VM100 services untouched.

**Architecture:** VM100 is still Docker standalone (`Swarm=inactive`), so this deployment uses per-service Docker Compose files under `/opt/apps`. Orange Pi `edge_traefik` continues to own public routing and proxies to VM100 LAN-only ports. Pi5 remains the datastore host; no PostgreSQL data is moved.

**Tech Stack:** Docker Compose on Ubuntu 22.04 VM100, Orange Pi Traefik file provider, VPS `gateway-traefik` HostSNI allow-list, Pi5 PostgreSQL/PgBouncer, n8n official Docker image, OpenClaw artifact discovered from the existing `10.10.0.12:18789` service or local source checkout.

**Spec:** User request on 2026-09-12: "Deploy opencalw và n8n lên VM100 plan". Current docs: `docs/VM100.md`, `docs/MAIN.md`, `migration/traefik/dynamic.yml`, `docs/MAC.md`.

## Global Constraints

- This plan is planning only; do not deploy until the operator approves execution.
- Do not deploy GoClaw and do not restore `goclaw.dungxbuif.com`.
- OpenClaw is a separate service from GoClaw and should use `openclaw.dungxbuif.com`.
- MyPocket remains outside this deployment and stays under `/Users/dungxbuif/workspace/MyPocket/` and `/Users/dungxbuif/production/mypocket/`.
- VM100 ports already in use: `18080`, `18081`, `18084`, `18085`. Reserve `18086` for OpenClaw and `18087` for n8n.
- Store secrets only in VM100 `.env` files with mode `0600`; never commit tokens, database passwords, n8n encryption keys, or OpenClaw secrets.
- Use pinned image tags or a recorded image digest. Do not deploy `latest`.
- n8n must have a stable `N8N_ENCRYPTION_KEY` before first start; losing it breaks credential decryption.
- Route changes must update both the repository `migration/traefik/dynamic.yml` and the live Orange Pi `/opt/edge/traefik/dynamic.yml`, plus the VPS HostSNI allow-list for public exposure.
- PostgreSQL remains on Pi5. Create or reuse only dedicated application databases and users; do not mutate shared databases with raw SQL beyond the explicit database/user/schema provisioning commands.
